# Колесо активностей

Интерактивное колесо со случайным выбором командной активности. Проект подготовлен как стандартное приложение Next.js для публикации на Vercel.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Публикация на Vercel

1. Откройте [vercel.com/new](https://vercel.com/new).
2. Импортируйте репозиторий `meloshnikov/daily`.
3. Оставьте Framework Preset: **Next.js** и стандартные параметры сборки.
4. Нажмите **Deploy**.

Переменные окружения и дополнительные сервисы проекту не требуются.
